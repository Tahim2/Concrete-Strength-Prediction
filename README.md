# Concrete Strength Prediction

This project predicts the compressive strength of concrete using machine learning models.

## 🚀 Overview

- Load and preprocess concrete dataset
- Train and evaluate models:
  - Linear Regression
  - Random Forest Regressor
  - XGBoost Regressor
- Perform hyperparameter tuning on XGBoost
- Analyze feature importance and explain predictions with SHAP

## 📦 Tools & Libraries

- Python, pandas, scikit-learn
- XGBoost
- SHAP, seaborn, matplotlib
